# Superseded community test candidate

The former `0.4.0-vehicle-test.5` community test candidate is **superseded**.

The validated architecture/workflow evolved through later internal vehicle-test builds and was promoted to the physically accepted stable **AE Tuner 0.4.0** baseline.

Current accepted stable artifact:

- `ae-tuner-epicefi-0.4.0.jar`
- SHA-256: `1af45f58584b0dda8a8e2eb9b78ddfb09276f407b9264ee74bbf9408d54b13d8`

Do not install or use `0.4.0-vehicle-test.5` as the current release, and do not treat tuning proposals generated by any historical vehicle-test build as automatically approved.

This `test-candidate/` directory is retained only temporarily while the public `0.4.0` publication is being cleaned up. It should be removed together with the obsolete candidate JAR once the stable `0.4.0` files are in place.

For current installation, usage, safety guidance, and log submission instructions, use the repository root `README.md`.
