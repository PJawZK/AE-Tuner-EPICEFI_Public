## Scope

`0.4.1` accepts the Passive/Guided session-export and report-format refactor built on the
accepted `0.4.0` runtime/architecture baseline.

Accepted user-facing changes:

- one visible export action for Passive: `Export Passive Session`;
- one visible export action for Guided: `Export Guided Session`;
- each system exports to its own uncompressed timestamped session folder;
- complete session folders are staged under a temporary name and promoted only after all
  files close successfully;
- export serialization runs in background Swing workers with visible in-progress/completion
  status;
- Passive export snapshots the current evidence before background writing;
- TXT reports prioritize summary/tuning results before detailed evidence and diagnostics;
- Guided spreadsheet exports are normalized rectangular CSVs rather than multi-line traces
  embedded inside individual cells;
- Guided events and diagnostics are separate CSVs inside the same Guided session folder;
- Passive report and captured event data remain together in the same Passive session folder.

No compression, XLSX dependency, ECU write path, burn path, automatic tune application,
interpolation/smoothing or capture-policy change was introduced.
